# LabFitnessTracker

## Purpose of Program
This program is used to track workouts.

## How to use Program
Currently the program will ask the user what workout they performed, the duration, and the distance. A calculation is then performed to determine calories burned. This information is then displayed back to the user.

## Example
```text
Enter workout type: Run
Enter duration (minutes): 90
Enter distance (km): 10
---Workout Summary---
Workout: Run
Duration: 90 minutes
Distance: 10.0 km
Calories Burned: 600.0 calories
```
